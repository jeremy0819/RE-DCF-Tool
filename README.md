# 🏗️ RE-DCF-Tool — 都更/危老前期評估工具

永盛開發建設內部工具。輸入土地與**逐層**建築參數，自動完成容積查核（建築技術規則 §162）、銷售坪效、開發評效，並偵測法規踩坑點。**圖說（面積表）為唯一真實依據**，本工具是查核器（oracle），負責逐層偵測超出並補計，不蓋過建築師圖說。

## ✨ v3 功能

- **逐層表格**：每層樓板/計容積/梯廳/安全梯/陽台實填，可勾選排除（B1F 防空避難室 §117）
- **Excel/CSV 一鍵匯入**面積表，自動填表
- **容積量表 + KPI 卡 + 結論橫幅**：一眼看出是否超出允建容積
- **三項免計逐層查核**：梯廳/安全梯/陽台（含 1/8 投影檢討），超出自動標紅並補計
- **雙法陽台檢討**：同步檢視陽台 10% 免計 + 1/8 投影兩種法則
- **銷售坪效 + 開發評效 + 敏感度熱力圖**
- **🆕 都更全案投報**：總銷 → 共同負擔六大科目（權利變換實施辦法）→ 共負比／地主分回／報酬率 + 售價×營造敏感度；另附 `都更全案投報_對照範本.xlsx` 供開啟舊 Excel 坪效分析表逐格對照
- **一頁報告匯出**（Markdown / CSV，含都更全案投報段）

## 🧮 核心邏輯（§162，全部逐層）

| 項目 | 計算 |
|------|------|
| 基準容積 FA | (基地面積 − 人行廣場) × 容積率 |
| 允建容積 | FA × (1 + 獎勵率) + 容積移轉 |
| 梯廳超出 | Σ 各層 max(0, 梯廳 − 樓板 × 梯廳免計%) |
| 陽台超出（免計%) | Σ 各層 max(0, 陽台 − 樓板 × 陽台免計%) |
| 陽台超出（1/8投影） | Σ 各層 max(0, 陽台 − 樓板 × 1/8)  |
| 安全梯上限 | 允建容積 × 15% |
| 計入容積(修正後) | 計入容積(圖說) + 梯廳超出 + 陽台超出 |
| 容積餘量 | 允建容積 − 計入容積(修正後)　（<0 = 超出需調整）|

> ⚠️ 陽台/梯廳超出必須**逐層**（樓板×%）判斷，**不可**用「總量 vs FA×%」——後者會把中正段超出量從正確的 29 m² 誤算成 303 m²（差 10 倍）。
